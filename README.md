# ❤️ Heart Disease Prediction — Machine Learning

## 📌 Project Overview

This project is an interactive **Heart Disease Prediction web application** built using **Python, Scikit-learn, Pandas, Joblib, and Streamlit**.

The objective is to analyze patient health parameters, identify patterns associated with heart disease, and predict whether a patient is at **high or low risk of heart disease**.

The project combines **data preprocessing, exploratory data analysis, feature engineering, feature scaling, supervised Machine Learning, model evaluation, model serialization, and Streamlit application development** to build an end-to-end Machine Learning solution.

---

## 🎯 Project Objectives

The application is designed to:

- Predict heart disease risk using **Supervised Machine Learning**.
- Analyze important clinical and patient health parameters.
- Perform **data cleaning and preprocessing**.
- Encode categorical features into Machine Learning-compatible representations.
- Apply **feature scaling** using StandardScaler.
- Train a **K-Nearest Neighbors (KNN)** classification model.
- Evaluate the Machine Learning model using classification metrics.
- Maintain consistent feature structure between training and prediction.
- Serialize the trained model and preprocessing objects using **Joblib**.
- Build an interactive **Streamlit web application**.
- Generate real-time heart disease risk predictions.

## 🧠 Feature Engineering

Feature engineering was performed to transform raw patient information into a structured numerical representation suitable for Machine Learning.

Major steps include:

- Encoding categorical variables
- Converting categorical values into numerical features
- Preparing numerical features
- Creating a consistent feature representation
- Handling missing encoded columns
- Maintaining the expected feature structure
- Maintaining the correct feature order during prediction

The expected feature columns and their order are stored in:

**heart_columns.pkl**

This ensures that the input generated by the Streamlit application follows the same feature structure used during model training.

---

## 📐 Feature Scaling

Feature scaling was performed using **StandardScaler** from Scikit-learn.

Standardization is particularly important for **K-Nearest Neighbors (KNN)** because KNN relies on distance calculations between observations.

The trained scaler is saved as:

**heart_scaler.pkl**

The same scaler is reused during application inference to ensure that new user inputs are transformed consistently with the training data.

---

## 🤖 Machine Learning Model

### K-Nearest Neighbors (KNN)

The project uses **K-Nearest Neighbors (KNN)** as the primary supervised Machine Learning classification algorithm.

KNN predicts the class of a new observation based on the classes of its nearest neighboring observations in the feature space.

The model is trained using the processed and scaled feature set.

The trained model is stored as:

**knn_heart_model.pkl**

---

## 📊 Model Evaluation

The Machine Learning model is evaluated using standard classification metrics.

The evaluation process includes:

- **Accuracy**
- **Precision**
- **Recall**
- **F1-Score**
- **Confusion Matrix**

These metrics help assess the classification performance of the trained KNN model.

---

## 💾 Model Serialization

After model training, the Machine Learning model and preprocessing objects are serialized using **Joblib**.

The project uses the following serialized files:

- **knn_heart_model.pkl** — Trained KNN classification model
- **heart_scaler.pkl** — Trained StandardScaler
- **heart_columns.pkl** — Expected feature columns and their order

Model serialization allows the Streamlit application to load the trained Machine Learning components directly without retraining the model every time the application starts.
